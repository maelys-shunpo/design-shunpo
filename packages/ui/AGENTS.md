# @repo/ui — design system

The only place where visual decisions live. Read the `design-system` skill before changing anything here.

Figma library: not yet mirrored for SHUNPO (the boilerplate's library describes the old starter). Sync it with the `figma-sync` skill once a direction is chosen; Code Connect templates live in `figma/`.

## Rules

- Tokens: `src/styles/theme.css` only. The theme is locked (`--*: initial`); a utility exists only if its token exists.
- Classes inside this package still obey the lint: no arbitrary values, no margins (except `*-auto`), no single-side padding, no `space-*`, on-scale z-index, durations and border widths.
- Every component: `cva` variants, `cn()` to merge `className`, `data-slot` on the root, named export, one component per file.
- Layout and typography components are Server-Component-safe (no hooks, typed `as` prop). Interactive components wrap Base UI, or a native element when the browser already provides the behaviour; links use `useRender` with a `render` prop.
- Every component has a story in `stories/` (stories are tests: `play` + accessibility check). A wrapper that draws nothing of its own (`AfterIdle`) has none: its tests cover it. Logic has unit tests in `tests/`.
- Import paths: `@repo/ui/<folder>/<file>` (no barrel files).
- Direction « Agents » corners (DESIGN.md « Coupe »): no radius, every surface is cut from `agents-sheet` (20 px; `-2xs` 8→10, `-xs` 10, `-sm` 12, `-md` 14, `-lg` 16, `-xl` 32, `-none` 0), papers `-paper`, `-wait`, `-ok`, `-info`, `-night`, `-bare` (no hairline), `-signal` (Fushimi hairline), `-fold` for notes, `-left` for a speaker on the left, shadows `-lift` and `-float` (drop shadows that follow the cut), `-ring` (hairline over title bars that paint their own ground) and `-clip` with `-ring` (the element itself clipped, its shadow on a parent). Actions keep `agents-cut`; inside a cut object, hairlines, never boxes.
- GSAP and Lenis never load before the first paint. A component that needs them puts that code in a module of its own and renders it lazily inside `AfterIdle`, as `MotionProvider` and `ScrollScene` do. Motion arrives after the visitor has seen the page painted, so an entrance never hides what is already in view: it goes through `enterUnseen` (`src/motion/enter-unseen.ts`), which plays it as unseen content enters the window and leaves content in view as painted. A static `gsap` import in a component of the first load puts it back on the critical path (about 50 KB gzipped) and costs Lighthouse mobile its LCP margin.
- A new or changed component updates its Code Connect template in `figma/<component>.figma.ts`. Canvas hosts and motion primitives (`Stage`, `ScrollScene`, `AfterIdle`, a project's effect components) have none: the Figma library holds their poster or their content, never their motion.
